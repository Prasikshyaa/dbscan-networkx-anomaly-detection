Project title:
DBSCAN-Based Anomaly Detection with NetworkX Graph Analysis

Short description:
A Python project demonstrating density-based clustering for transaction
anomaly detection and NetworkX-based relationship analysis. DBSCAN identifies
observations that do not belong to dense behavioral groups, while NetworkX
represents customer-transaction-merchant relationships surrounding the
flagged observations.
